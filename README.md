# AliKa atölye belgeleri

Bu dal yalnız AliKa atölyesinin proje belgelerini taşır. Ders verisi, soru bankası, konu anlatımı, ses dosyası veya uygulama paketi içermez. Geçmişi `main` dalından ayrıdır; uygulamanın indirdiği içerik paketleri ve yayın kayıtlarıyla bağlantısı yoktur.

| Dosya | Kaynak |
|---|---|
| `PROJE_BILGISI_VE_HEDEFLER.md` | AliKa atölyesinin yerel deposu (`atolye/AliKa atölye/`) |
| `PROJECT_INDEX.md` | Yerel çalışma alanının kökü (`AliKa_Projeleri/`); Git dışında tutulur |

Belgelerdeki göreli bağlantılar yerel atölye ve çalışma alanı klasörlerine göre yazılmıştır; bağlantılı dosyaların çoğu bu dalda yoktur.

Bu dala yalnız proje belgeleri eklenir. Ders verisi `main` dalına, kendi yayın kapıları ve pull request süreciyle gider.
